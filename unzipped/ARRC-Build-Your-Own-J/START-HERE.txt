BUILD YOUR OWN J
You call a phone number, talk to J, and your laptop does what you ask.
Built on Sarvam AI by Hari and Anurag at the Sarvam AI hackathon,
in collaboration with IIT Hyderabad.

BEFORE YOU START, YOU NEED
  - A Windows laptop.
  - A Sarvam account at indus.sarvam.ai with some credits,
    and a phone number in it (Deploy, then Phone Numbers).
That's it. Everything else installs itself.


=====================================================================
 WAY 1 (easiest): Claude Code does it with you        about 20 min
=====================================================================

  1. Install the Claude Code app from claude.com/claude-code
     and sign in.
  2. In Claude Code, open this folder (ARRC-Build-Your-Own-J).
  3. Type:   Set up J for me
  4. Do what it says. It tells you exactly where to click, and puts
     everything you need on your clipboard, so you just press Ctrl+V.


=====================================================================
 WAY 2: on your own, just double-clicks                about 30 min
=====================================================================

PART A. Switch J on (on your laptop)

  1. Double-click  Start-J.bat
     If Windows asks "Do you want to allow this app...", click Yes.
     The first time it installs what it needs (a few minutes).
  2. It asks for your mobile number. Type it with the country code,
     numbers only, like 919876543210, and press Enter.
  3. Wait until it says  J is running.  Keep that window open.
     (Closing it switches J off.)

PART B. Make J on the Sarvam website

  Double-click  Copy-for-Sarvam.bat . Every time a step below says
  "copy N", press that number and Enter in it, then go to the website
  and press Ctrl+V.

  1. Go to indus.sarvam.ai. Click Build, then Agents, then
     Create from scratch. Name it J.
  2. Instructions box: copy 1, paste.
  3. Variables: add one called  opening_line . For its value, copy 2,
     paste.
  4. Greeting: type  {{opening_line}}
     (if it asks for translations, type the same thing there too).
  5. Settings: pick any voice. Starting language: English.
     Switch language during call: ON.
     Hang up after unanswered nudges: OFF.  Background sound: none.
  6. Tools, then Add tool, then API / HTTP tool:
       Name:          laptop_action
       Description:   copy 3, paste
       When it runs:  During call
       Method:        POST
       URL:           copy 4, paste
       Auth:          Bearer token. Make a new secret: copy 5, paste.
       Parameters:    action  (text, filled by the agent)
                      input   (text, filled by the agent)
                      caller  (choose User Identifier)
       Max wait:      10 seconds
  7. Press Test agent and say "what's my battery?". J should answer.
  8. Press Commit. Then go to Deploy, Phone Numbers, pick your number,
     and set Inbound to agent J and the version you just committed.

PART C. Call J

  1. Call your Sarvam number from your own phone. Try:
     "Play Arijit Singh on YouTube"  or  "Set a 5 minute timer for tea".
  2. It works? In Copy-for-Sarvam.bat press 6. Now J only listens
     to your phone.


=====================================================================
 EVERY DAY
=====================================================================

  Switch J on: double-click Start-J.bat and keep the window open.
  If the window says the address CHANGED: in Sarvam open J, Tools,
  laptop_action, paste into URL (it's already copied), press Commit,
  and set the new version on your phone number. Claude Code can do
  this with you too: just ask it.


IF SOMETHING GOES WRONG
  J says she can't reach your laptop  -> Start-J.bat isn't open, or the
                                         address changed (see EVERY DAY).
  "I can only take orders from my owner's phone" -> wrong mobile number.
     Open arrc\.env in Notepad, fix OWNER_NUMBER, save.
  She starts in Hindi        -> Settings, Starting language: English.
  She hangs up by herself    -> Hang up after unanswered nudges: OFF.
  Or open the folder in Claude Code and tell it what happened.

More (J calling you, Google Classroom, adding your own actions):
see ARRC-Build-Guide.pdf.

Never share the file arrc\.env. It holds J's password.
Have fun, and go build your own J.
