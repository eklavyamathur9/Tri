# Tri - Linux Setup Guide

Complete step-by-step guide to set up Tri on Linux for voice-controlled laptop automation.

## Prerequisites

### Required
- **Linux** (tested on Kali/Ubuntu/Debian, should work on most distros)
- **Node.js 18+** - Check with `node -v`
- **npm** - Comes with Node.js
- **cloudflared** - Cloudflare tunnel to expose local server
- **curl, xdg-utils** - Usually pre-installed

### Recommended (for full functionality)
| Tool | Purpose | Install (Debian/Ubuntu/Kali) |
|------|---------|----------------------------|
| `xclip` / `wl-clipboard` | Clipboard copy/paste | `sudo apt install xclip wl-clipboard` |
| `xdotool` / `ydotool` / `wtype` | Key simulation for media/shortcuts | `sudo apt install xdotool ydotool` |
| `playerctl` | Media player control (MPRIS) | `sudo apt install playerctl` |
| `flameshot` / `grim` / `scrot` | Screenshots (flameshot recommended for GNOME Wayland) | `sudo apt install flameshot` or `sudo apt install grim scrot` |
| `spd-say`/`espeak-ng`/`festival` | Text-to-speech | `sudo apt install speech-dispatcher-espeak-ng espeak-ng` |
| `notify-send` (`libnotify-bin`) | Desktop notifications | `sudo apt install libnotify-bin` |
| `bluetoothctl` (`bluez`) | Bluetooth device management | `sudo apt install bluez` |
| `upower` | Battery status | `sudo apt install upower` |
| `wpctl`/`pactl`/`amixer` | Volume and mic mute control | Usually available with PipeWire/PulseAudio |
| `loginctl`/`xdg-screensaver` | Lock screen / sleep | Usually pre-installed |

Run the dependency checker:
```bash
./scripts/check-deps.sh
```

## Installation

### Step 1: Get the Code
```bash
cd ~/Projects
git clone https://github.com/eklavyamathur9/Tri.git
cd Tri
```
Or if already cloned, pull latest changes.

### Step 2: Install Node Dependencies
```bash
cd tri
npm install
cd ..
```

### Step 3: Run Initial Setup
```bash
./scripts/start-tri.sh
```

On first run, this will:
1. Check for Node.js and cloudflared
2. Install dependencies if needed
3. Ask for your mobile number (with country code, digits only)
4. Generate a secure token and create `tri/.env`
5. Start the server and cloudflared tunnel
6. Copy the tool URL to your clipboard

**Keep this terminal open** - closing it stops Tri.

### Step 4: Configure Your Voice Agent

You'll need a voice agent platform account. This project is set up for [Sarvam AI](https://indus.sarvam.ai/), but should work with others that support HTTP tools.

Use the helper script:
```bash
./scripts/copy-for-sarvam.sh
```

Or manually configure:

| Setting | Value | Notes |
|---------|-------|-------|
| **Agent Name** | `Tri` | Or anything you prefer |
| **Instructions** | Copy from `prompts/tri-instructions.txt` | The agent's personality and capabilities |
| **Greeting Variable** | Create variable `opening_line` with: `Hey Boss, it's Tri. What can I do for you?` | Set as greeting |
| **Tool Name** | `laptop_action` | |
| **Tool Type** | HTTP/API POST | |
| **Tool URL** | From `tri/tunnel-url.txt` or clipboard | e.g., `https://xxx.trycloudflare.com/action` |
| **Auth** | Bearer token | Use the token from `tri/.env` (TRI_TOKEN) |
| **Parameters** | `action` (text, filled by agent), `input` (text, filled by agent), `caller` (User Identifier) | |
| **Timeout** | 10 seconds | Recommended |

### Step 5: Test & Lock Down
1. Call your agent's phone number
2. Try commands like: "What's the battery status?", "Open Firefox", "Set a 2 minute timer"
3. Watch activity on http://localhost:3710
4. Once working, lock to your phone only:
```bash
./scripts/copy-for-sarvam.sh 6
# or manually set ALLOW_NO_CALLER=false in tri/.env
```

## Daily Usage

```bash
# Start Tri (keep terminal open)
./scripts/start-tri.sh

# Or from tri directory
cd tri && node start.js
```

**Notes:**
- If the tunnel URL changes (after restart), update it in your voice agent's tool config
- Dashboard is always available at http://localhost:3710
- Tri only responds to your configured phone number when locked

## Configuration

All settings are in `tri/.env`:

```env
PORT=3710
TRI_TOKEN=<auto-generated>
OWNER_NUMBER=<your number with country code>
ALLOW_NO_CALLER=true  # Set to false to lock
```

**Never share or commit `tri/.env`** - it contains your auth token.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| "cloudflared not found" | Install from https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/ or use the binary method |
| "Tri says she can't reach laptop" | Start script not running, or tunnel URL changed. Restart and update URL in agent config. |
| "I can only take orders from my owner's phone" | Check `OWNER_NUMBER` in `tri/.env` - must be digits only with country code. Set `ALLOW_NO_CALLER=false` after testing. |
| App won't open | Check if app is installed. Update `APPS` in `tri/server.js` or use platform app mapping. |
| Screenshots not working | Install `grim` (Wayland) or `scrot`/`maim` (X11). Check display server with `echo $WAYLAND_DISPLAY $DISPLAY`. |
| Media controls not working | Install `playerctl` for MPRIS apps, or ensure `xdotool`/key support works. Some Wayland compositors restrict this. |
| No TTS | Install `spd-say`, `espeak-ng`, or `festival`. |
| Battery shows "no battery reading" | Normal on desktops. Uses `upower` - install if missing. |

## Architecture

```
Phone Call → Sarvam Voice Agent → Cloudflare Tunnel → Tri Server (localhost:3710)
                                                            ↓
                                                      Platform Layer
                                                       (Linux/Windows)
                                                            ↓
                                                      System Commands
                                                    (apps, media, files, etc.)
```

## Security Notes

- Server only accepts requests with valid Bearer token
- Owner phone number filtering (can be enforced with `ALLOW_NO_CALLER=false`)
- Action allowlist - only predefined actions can be executed
- No arbitrary shell command execution from voice commands
- `.env` file contains secrets - never commit it
- All actions go through the platform abstraction layer
